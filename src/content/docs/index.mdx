**Turn confusion into systems.**

## Reading paths

If you are here for production AI systems, start with [AI Infrastructure](/ai-infrastructure/) and [Inference Systems](/inference-systems/). If you are reading protocol behavior, start with [Protocols](/protocols/). If you are interested in coding agents and repeatable developer workflows, start with [Agent Infrastructure](/agents/).

Posts are chronological and useful for following the work over time. Docs pages are the maintained version of ideas that still matter.

## Operating rules

- Write in Markdown or MDX.
- Keep each page focused on one engineering question.
- Prefer concrete observations, examples, and references over broad summaries.
- Retire weak content instead of carrying an old archive forever.
- Keep private or historical material out of the public surface unless it has been rewritten for readers.
- Turn small observations into reusable systems over time.
