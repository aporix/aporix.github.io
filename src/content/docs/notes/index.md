Notes are the smallest durable unit in Aporix.

A note should preserve one useful observation, question, model, or trade-off. It does not need to be complete. It needs to be clear enough to reuse later.

## Note Shape

A good small note usually has:

- one question
- one context
- one observation
- one model
- one conclusion

That is enough.
