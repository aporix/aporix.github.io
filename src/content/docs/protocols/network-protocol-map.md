This page comes from the old blog archive and now serves as a protocol reading index.

The original scope was broad: HTTP, WebSocket, HTTP/2, HTTP/3, TLS/SSL, TCP/IP, and related web protocol behavior.

## Reading map

- HTTP request/response model
- WebSocket upgrade and persistent message flow
- HTTP/2 multiplexing and stream behavior
- HTTP/3 and QUIC transport changes
- TLS handshake, certificates, and encrypted transport
- TCP connection lifecycle, congestion, retransmission, and buffering

## Future direction

Turn each protocol into a short note:

- what problem the protocol solves
- what the wire format looks like
- what state machines are involved
- what breaks in real deployments
