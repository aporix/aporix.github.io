这个页面作为协议阅读入口，用来把分散主题整理成可检索的短笔记。

## 阅读地图

- HTTP request/response 模型
- WebSocket upgrade 和持久消息流
- HTTP/2 multiplexing 和 stream 行为
- HTTP/3 与 QUIC 带来的传输层变化
- TLS 握手、证书和加密传输
- TCP 连接生命周期、拥塞、重传和缓冲

## 后续整理方向

每个协议都应该逐步整理成短笔记：

- 它解决什么问题
- 线格式是什么
- 涉及哪些状态机
- 真实部署中容易在哪里出问题
